# RfamAlign3D

**Testing Rfam seed-alignment correspondences against 3D structural alignment.**

Rfam seed alignments are curated multiple sequence alignments of RNA families. They are guided by a consensus
secondary structure, and Rfam has begun to revise families with 3D structures (65 in Rfam 15.0), but most seed
alignments have not been checked against 3D structure. RfamAlign3D links Rfam 15.1 seed rows to experimentally
determined, natural RNA structures, aligns pairs of those structures from different species with the 3D aligner
STAR3D, and compares the two sets of nucleotide correspondences. Where they disagree, it asks which correspondence
preserves the base pairs, canonical and noncanonical, annotated by two independent tools (MC-Annotate and FR3D),
without treating either alignment as ground truth, and reports candidate corrections for curator review.

*Formerly developed under the working name SQARMA; that name still appears in some internal identifiers.*

## Main results (cohort `step2_r8`)

| | Value |
|---|---|
| Rfam 15.1 families screened | 4,227 |
| Families with a seed row matching a PDB chain exactly | 105 |
| Chains verified as natural sequences | 844 (142 more not evaluated because they could not outrank a selected chain) |
| Cross-species pairs aligned with STAR3D | 570 (11 families); 538 aligned (10 families) |
| Assessable nucleotides placed differently by the two methods | **18.6%** (95% CI 16.8–20.5%, resampling pairs) |
| …of which: different partner / Rfam only / STAR3D only | 4,676 / 3,234 / 1,086 nucleotides |
| Differences that are one-nucleotide shifts | 83.3% (80.4–86.1%) |
| Difference rate in BGSU hairpin loops vs outside | 14.4% vs 9.4% (difference 4.9 points, 3.6–6.1) |
| Canonical A–U/G–C pairs preserved at disagreements, Rfam vs STAR3D | 50.2% vs 49.3% (648 and 636 of 1,290; similar observed rates) |
| Noncanonical pairs preserved at disagreements, pooled | 13.8% vs 27.6% (588 pairs); not robust to shared sequences (sequence bootstrap −4.2 to +32.2 points) |
| **…5S rRNA** | **11.9% vs 43.7%** (293 pairs; FR3D 10.8% vs 50.6%) |
| **…tRNA** | **18.0% vs 8.8%** (250 pairs; FR3D 21.5% vs 13.1%): here the seed alignment does better |
| Disagreement regions favoured by interactions (both annotators) | STAR3D 218 (74 strong), Rfam 208 (55 strong), of 1,155 |
| Candidate seed correction | RF00001 *M. tuberculosis* and *M. smegmatis* rows, helix IV ([`outputs/06_audit/step2_r8/correction_case/`](outputs/06_audit/step2_r8/correction_case/)) |

"Preserved" means the two mapped nucleotides form a base pair of the same Leontis–Westhof class, compared in mapped
order, counted over pairs whose both nucleotides are mapped under both methods. Definitions, the earlier (withdrawn)
region verdicts and the reasons are in [`docs/DECISIONS.md`](docs/DECISIONS.md) (audit A1–A6). Intervals labelled
"resampling pairs" treat RNA pairs as independent although one sequence occurs in many pairs; read them as descriptive.

Every number is generated by the pipeline; `docs/results.json` holds them all and `scripts/verify.py` recounts the
headline ones from the raw tables.

## Check it yourself
```bash
python3 scripts/verify.py        # checksums + independent recount; standard library only
```
See [`docs/REPRODUCE.md`](docs/REPRODUCE.md) for the release archives, the interactive browser and full reruns.

## Data sources and versions
Rfam 15.1 (seed alignments, PDB mapping, motif matches) · RCSB PDB mmCIF files (revision recorded per entry) ·
NCBI taxonomy (snapshot 2026-11-13) and NCBI sequence records · STAR3D v1.2 with its bundled MC-Annotate · FR3D (fr3d-python, commit 288f98c) ·
BGSU RNA 3D Hub loops and RNA 3D Motif Atlas 4.16. Checksums are in `config.yaml`, `logs/sources_manifest.tsv` and the
snapshot manifest.
