# RfamAlign3D

**Testing Rfam seed-alignment correspondences against 3D structural alignment.**

Rfam seed alignments are curated multiple sequence alignments of RNA families, guided by a consensus secondary
structure that encodes canonical base pairs but not the noncanonical interactions that shape RNA 3D architecture.
RfamAlign3D links Rfam 15.1 seed rows to experimentally determined, natural RNA structures, aligns pairs of those
structures from different species with the 3D aligner STAR3D, and compares the two sets of nucleotide
correspondences. Where they disagree, it asks which correspondence preserves the base pairs, canonical and
noncanonical, that define the structure, and reports candidate corrections to the seed alignment.

*Formerly developed under the working name SQARMA; that name still appears in some internal identifiers.*

## Main results (cohort `step2_final`)

| | Value |
|---|---|
| Rfam 15.1 families screened | 4,227 |
| Families with a seed row matching a PDB chain exactly | 105 |
| Chains verified as natural sequences | 884 |
| Cross-species pairs aligned with STAR3D | 535 (11 families); 503 aligned (10 families) |
| Assessable nucleotides placed differently by the two methods | **19.0%** (95% CI 17.2–21.1%, resampling pairs) |
| …of which: different partner / Rfam only / STAR3D only | 4,281 / 3,164 / 994 nucleotides |
| Differences that are one-nucleotide shifts | 82.4% (79.4–85.5%) |
| Difference rate in BGSU hairpin loops vs outside | 14.6% vs 9.1% (difference 5.5 points, 4.2–6.8) |
| Canonical Watson–Crick pairs kept at disagreements, Rfam vs STAR3D | 49.4% vs 48.8% (no difference) |
| **Noncanonical pairs kept at disagreements, Rfam vs STAR3D** | **9.7% vs 21.4%** (difference 11.7 points, 5.9–17.8) |
| Disagreement regions supporting STAR3D / supporting Rfam | 195 / 107 (of 1,074) |

Every number is generated by the pipeline; `docs/results.json` holds them all and `scripts/verify.py` recounts the
headline ones from the raw tables.

## Check it yourself
```bash
python3 scripts/verify.py        # checksums + independent recount; standard library only
```
See [`docs/REPRODUCE.md`](docs/REPRODUCE.md) for the release archives, the interactive browser and full reruns.

## Data sources and versions
Rfam 15.1 (seed alignments, PDB mapping, motif matches) · RCSB PDB mmCIF files (revision recorded per entry) ·
NCBI taxonomy (snapshot 2026-11-13) and NCBI sequence records · STAR3D v1.2 with its bundled MC-Annotate ·
BGSU RNA 3D Hub loops and RNA 3D Motif Atlas 4.16. Checksums are in `config.yaml`, `logs/sources_manifest.tsv` and the
snapshot manifest.
